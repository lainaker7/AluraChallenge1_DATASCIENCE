# **AluraChallenge1_DATASCIENCE**
🥇
Este primer desafío del programa ORACLE-ALURA LATAM para Data_science consiste en aplicar 
los conocimientos adquiridos durante la primera fase de la formación. El propósito principal es
analizar una seria de datos que permitan tomar una decisión basada en los resultados
y poder brindar solución al cliente final.

 ### *Conociendo los datos* 🥸🧐

Siguiendo el Back-log en TRELLO se hace un pequeño desglose de los datos para poder entender qur tipos
de datos tenemos, como están organizados, cuales son los principales items motivos del análisis, para poder llegar 
a la mejor conclusión
